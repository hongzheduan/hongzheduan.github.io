Revert to Billing

Step-by-step guide to re-enabling paid subscriptions after the time-limited free period.
All changes were made on top of a clean billing-enabled baseline. This document reverses every one of them.

⚠ Prerequisite: Do NOT re-enable billing while on yfinance data. Confirm Tiingo scanner has run cleanly for at least one full week before proceeding. As of 2026-06-07, Tiingo has been live and producing clean compare logs — this gate is met.

Quick Find

Every temporary change is marked with a comment. Search these strings across all HTML files:

  • // TEMP: — JS login gates and dashboard items
  • <!-- TEMP: — HTML blocks (nav links, cards, CTAs)
  • // FREE MODE: — subscription check block in main form
  • mobile-dash-btn — mobile header Dashboard button (CSS + HTML in index.html / index_cn.html)

In VS Code: Ctrl+Shift+F → search TEMP: to find all HTML blocks and most JS gates. Also search FREE MODE: separately — login.html and baizora_main_form.html use that marker instead of TEMP:.
