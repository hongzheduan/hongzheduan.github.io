Revert to Billing

How to turn paid subscriptions back on after the site-wide free-access period.
Everything is driven by one flag — this doc explains what that covers automatically and what still needs a human.

✓ Good news: almost none of this is a manual multi-file edit anymore. Every page's HTML source was kept as its original, paid-mode copy the whole time — a JS flag decides at page-load whether to show the free-access version. Flip the flag off and nearly everything reverts by itself.

The One Step

Open assets/feature_flags.js and change:

window.FREE_ACCESS_MODE = true;
window.FREE_ACCESS_MODE = false;

Commit and push. That's it for the flag-controlled part of the system — see below for what that single edit actually restores, and what it deliberately does not touch.

What Reverts Automatically

All of the following read window.FREE_ACCESS_MODE at runtime. Once it's false, they all fall back to their original paid-mode behavior with no other code changes:

Paywalls re-enable

  • dashboard.html / _cn — Scanner and Index Membership News tool cards lock again for non-subscribers, with the "→ Please choose a plan to view" tag
  • index_news.html / _cn and market_news.html / _cn — redirect non-subscribers to billing.html again
  • index.html / _cn — hpViewAll (homepage "View all" links, incl. Index News and Market Briefing) drops the || window.FREE_ACCESS_MODE short-circuit, so signed-out visitors get the "Subscription Required" gate modal again instead of being sent straight to the login page, and signed-in users are re-checked against real subscription status
  • baizora_main_form.html / _cn (the Scanner itself) — its own subscription check re-enables (this also fixed a real dormant bug found while wiring the free-access flag: this page was calling a Cloud Function endpoint that doesn't exist, so it was already unconditionally open before the free-access period even started — that's fixed now, so this check will work correctly this time)
  • login.html / _cn — post-login redirect goes back to checking real subscriptionStatus (active/trialing → dashboard, otherwise → billing) instead of always going straight to the dashboard
  • pricing.html / _cn and billing.html / _cn — the redirect-away-on-load script (if (window.FREE_ACCESS_MODE) window.location.replace(...)) stops firing, so both pages become directly visitable again instead of bouncing every visitor to the homepage. Added because visitors could still reach these by typing the URL directly even with nav links hidden — hiding a link doesn't block the page itself. Note: this was previously a deliberate exception (billing.html was left untouched so real subscribers could still manage an active subscription) — revisit whether that's still true if there are ever real paying customers again before re-enabling this redirect in a future free-access period

"Free Tier" naming reverts everywhere

This was the trickiest part to get right, and it's now fully generic. assets/feature_flags.js contains a small function that walks every text node on any page that loads it and renames "Free Tier" → "Preview" (CN: "免费版" → "预览") only while the flag is on. No page's actual HTML source was ever changed to say "Preview" — it always says "Free Tier" in the file itself. So once the flag is off, this function simply doesn't run, and every one of these goes back to "Free Tier" automatically, with zero file edits. (Rename target was "Top Movers" until 2026-08-11, when it was changed to "Preview" — a permanent wording call, not itself meant to be switched back.)

(2026-08-11), so that one no longer goes through this rename at all, in either mode
  • Dashboard tool card and quick-link (dashboard.html / _cn)
  • All 24 stocks/*.html nav links
  • unusual-volume.html and top-price-movers.html CTA buttons

FAQ content (assets/faq.html / _cn)

  • The new "Is Baizora free?" item disappears again (it's hidden by default in the HTML and only shown by JS while the flag is on)
  • The "How does the 7-day free trial work?" item and the entire "Subscription & Billing" section (subscribe flow, manage/cancel, monthly vs yearly, promo codes, trial-ends policy, duplicate-trial policy, refund policy, "subscribed but can't access dashboard") all reappear

  • "Where do I go after logging in?" — reverts from "you're taken directly to your Dashboard" back to the active-subscriber-vs-unsubscribed routing explanation

Verification Steps

  1. 1 Flip FREE_ACCESS_MODE to false in assets/feature_flags.js, commit, push
  2. 2 Wait 1–3 minutes for GitHub Pages to propagate, then hard-refresh (Ctrl+Shift+R)
  3. 3 Sign in as a test account with no active subscription → should land on billing.html, not the dashboard
  4. 4 On the dashboard, confirm the Scanner and Index News cards show the locked "→ Please choose a plan to view" tag for that account
  5. 5 Confirm the homepage nav, hero CTAs, and dashboard quick-links show "Free Tier" / "Plans" again, not "Preview" / hidden
  6. 6 Check the FAQ — "Subscription & Billing" section and the trial item should be back, "Is Baizora free?" should be gone
  7. 7 Subscribe as the test account → verify the dashboard unlocks and account.html shows real "Active" status
  8. 8 Visit pricing.html and billing.html directly by URL — both should load normally again instead of redirecting to the homepage
  9. 9 Manually rewrite about.html / _cn and compare.html / _cn pricing copy, and decide whether to restore pricing messaging on top-price-movers.html / unusual-volume.html (see table above)
