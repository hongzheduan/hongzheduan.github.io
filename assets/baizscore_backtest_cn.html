贝佐拉评分：历史回测

假设性回测数据 · 非真实业绩记录 · 非投资建议

阅读以下数据前请先看这里。 本页将贝佐拉评分公式套用于历史价格数据，模拟"如果在评分达到某一阈值的那天参考该分数，之后理论上会发生什么"。 这是对历史数据的回测——不是真实的业绩记录，不构成投资策略，也不是买入、持有或卖出任何证券的建议。

本次回测区间（2023年8月–2026年8月）恰逢美国大盘股的一段强劲牛市，这种环境天然利好趋势跟随型信号（本评分正属此类）——尚未在下跌行情中验证过。 过往规律不能预测未来结果。在得出任何结论前，请先阅读下方的局限性部分。

01 — 本次回测测试了什么

将评分公式套用于历史数据

贝佐拉评分由五项分项信号加权组成，每一项在正式看板上都已逐日计算：

RS 相对强度 — 30% // 百分位排名，衡量相对全市场的价格动能 动能 — 25% // 百分位排名，衡量更短周期的加速度 突破 — 20% // 当日价格/成交量相对21日均值 趋势一致性 — 15% // 6个周期中价格上涨的比例 量压 — 10% // 成交量强度 × 价格方向

为了检验某一评分阈值与之后走势的关系，上述公式被套用到了过去约三年内的每一个交易日——而不仅是今天——覆盖当前标普500 + 纳斯达克100成分股中的516只（另有2只因数据格式问题被排除），以每日价格数据为输入。只有当某只股票已积累满一年历史交易数据时，当天才会被计入评分——上市较晚或历史数据不足的股票会被排除，而不是用不完整数据打分。每一个被评分的交易日随后都会与该股票之后实际发生的1、3、6、9、12个月价格变化进行匹配。

最终得到 380,044 条独立的（日期、股票、评分）观测记录，覆盖 2023-08-16 至 2026-08-14。

02 — 局限性（请先阅读）

为什么这些数字需要上下文

  • 单一、偏向有利的市场环境。 整个回测区间处于同一段持续牛市中。评分中约一半的权重（RS + 动能）明确属于趋势跟随型，在趋势延续期间表现天然容易偏好——本回测无法说明该评分在2022年、2008年或其他下跌行情中会如何表现，因为这段区间的数据根本不在样本内。
  • 观测样本并不独立。 同一只股票会在连续多个交易日被评分，且各自的"之后走势"窗口高度重叠。下方的样本量是"股票-交易日"计数，而非独立的投资决策——应作为描述性数据看待，而非经过严格统计显著性检验的结论。
  • 收益分布右偏。 少数几只涨幅巨大的个股足以把平均值拉高，超出"典型"表现。因此下方同时列出中位数，通常中位数更能代表一般情况。
  • 成分股存在幸存者偏差。 回测统一使用了当前的标普500/纳斯达克100成分股名单，而非每个历史日期的真实成分股名单——这是常见的简化处理方式，会带来轻微的幸存者偏差。
  • 阈值越高，样本量下降越快。 70分以上的样本量相对充足；90分以上在拥有完整12个月后续窗口的样本不足600条，数据量偏薄，其结果只能作为方向性参考。

03b — 低评分能否预测下跌？

该评分并非对称信号

以上内容测试的都是上行方向：高评分是否预示更强的后续涨幅？我们用完全相同的方法反向测试了一遍： 低评分（≤10 / ≤20 / ≤30）是否预示弱于平均或下跌的后续走势——同时给出胜率与亏损率。

诚实的结论是：这是一个微弱且不稳定的下行信号，远不及上行信号那样有力。 在中期（3–9个月），低评分确实呈现出真实但很小的负向偏离（中位数超额约−0.4pp至−2pp之间）。 但到12个月时，这种偏离会减弱甚至转为正值，且每个周期的胜率都维持在56–66%的多数区间——亏损率从未接近50%，更不用说超过50%。 对比一下量级：评分≥80档的12个月中位数超额是+17.0pp；评分≤30档是−0.6pp。上行信号大约是下行信号的30倍。

这与其说是缺陷，不如说是一种结构性特征：该评分的每一项分量（RS、动能、突破、趋势、量压）衡量的都是"强势信号是否出现"，而非"弱势信号是否出现"。 低评分意味着这些强势信号没有触发——并不意味着相反的信号（破位、派发、持续恶化）正在发生。 将这些同属"衡量优秀程度"的分量以其他方式重新组合（已针对下文的贝佐拉持续度与贝佐拉信心指数进行测试）也不会改变这一点——它们的低分端呈现的是同样微弱、逐渐消退的模式，而非更清晰的下行信号。 请将低评分理解为"当前未显示强势"，而非"预示将要下跌"。

04 — 测试不同权重组合

现行权重与其他方案的对比

我们用同样的分项评分数据，重新组合出另外五种权重方案，并放入与上文完全相同的回测流程中。这项测试只是在检验"权重设置是否重要"，而不是在检验"评分是否有效"——上文提到的市场环境依赖与小样本注意事项，在这里同样适用。

下表按中位数超额排序，而非均值——上文第03节显示，同一数据的均值与中位数可相差2–3倍，中位数更能代表"典型情况"。均值口径的对照数字见表格下方说明。

超额 = 该分组12个月中位数后续涨跌幅，减去同期基准中位数，单位为百分点。作为对照，均值口径的超额普遍是中位数口径的2–3倍（例如现行方案在≥90档，均值口径为+67.9pp，中位数口径仅为+22.8pp）——这直接说明第03节中的分布偏态在多大程度上抬高了均值数字。

这项对比谨慎地提示了什么： 改用中位数后，同样没有任何一种权重方案在所有阈值上都领先——现行方案在70分档与等权重方案基本打平（+7.8pp vs. +7.9pp），在80分档小幅领先（+17.0pp vs. 动能强化方案的+16.5pp），只在样本偏薄的90分档明显落后于动能强化方案（+22.8pp vs. +28.8pp）。将"突破"与"量压"权重压低至接近零的两种方案，在中位数口径下依然是所有阈值中表现最弱的——趋势一致性倾斜方案在70分档的超额几乎归零（+1.6pp），其中一个周期（3个月）在中位数口径下甚至转为负值（详见原始数据），这比均值口径给出的信号更清晰地说明这两项分量确实携带了信息，而非与RS/动能重复。考虑到上述局限性，这仍应被视为未来权重复核的一项参考数据，而非可直接采纳的结论。

更新 — 2026-08-16：上文讨论的"动能强化"权重方案，现已作为第二项评分 贝佐拉动能+（BaizMomentum）上线到正式看板（评分标签页，紧邻贝佐拉评分与转势评分）。 它是一个补充视角，而非替代方案——上述数据仅在样本最薄的90分档明确显示出优势，且与本页其余内容适用同样的局限性说明。
