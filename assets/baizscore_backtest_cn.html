贝佐拉评分：历史回测

假设性回测数据 · 非真实业绩记录 · 非投资建议
发布于2026年8月16日 · 建议复核周期：每年一次，随数据积累更新

阅读以下数据前请先看这里。 本页将贝佐拉评分公式套用于历史价格数据，模拟"如果在评分达到某一阈值的那天参考该分数，之后理论上会发生什么"。 这是对历史数据的回测——不是真实的业绩记录，不构成投资策略，也不是买入、持有或卖出任何证券的建议。

本次回测区间（2023年8月–2026年8月）恰逢美国大盘股的一段强劲牛市，这种环境天然利好趋势跟随型信号（本评分正属此类）——尚未在下跌行情中验证过。 过往规律不能预测未来结果。在得出任何结论前，请先阅读下方的局限性部分。

01 — 本次回测测试了什么

将评分公式套用于历史数据

贝佐拉评分由五项分项信号加权组成，每一项在正式看板上都已逐日计算：

RS 相对强度 — 30% // 百分位排名，衡量相对全市场的价格动能 动能 — 25% // 百分位排名，衡量更短周期的加速度 突破 — 20% // 当日价格/成交量相对21日均值 趋势一致性 — 15% // 6个周期中价格上涨的比例 量压 — 10% // 成交量强度 × 价格方向

为了检验某一评分阈值与之后走势的关系，上述公式被套用到了过去约三年内的每一个交易日——而不仅是今天——覆盖当前标普500 + 纳斯达克100成分股中的516只（另有2只因数据格式问题被排除），以每日价格数据为输入。只有当某只股票已积累满一年历史交易数据时，当天才会被计入评分——上市较晚或历史数据不足的股票会被排除，而不是用不完整数据打分。每一个被评分的交易日随后都会与该股票之后实际发生的1、3、6、9、12个月价格变化进行匹配。

最终得到 380,044 条独立的（日期、股票、评分）观测记录，覆盖 2023-08-16 至 2026-08-14。

02 — 局限性（请先阅读）

为什么这些数字需要上下文

  • 单一、偏向有利的市场环境。 整个回测区间处于同一段持续牛市中。评分中约一半的权重（RS + 动能）明确属于趋势跟随型，在趋势延续期间表现天然容易偏好——本回测无法说明该评分在2022年、2008年或其他下跌行情中会如何表现，因为这段区间的数据根本不在样本内。
  • 观测样本并不独立。 同一只股票会在连续多个交易日被评分，且各自的"之后走势"窗口高度重叠。下方的样本量是"股票-交易日"计数，而非独立的投资决策——应作为描述性数据看待，而非经过严格统计显著性检验的结论。
  • 收益分布右偏。 少数几只涨幅巨大的个股足以把平均值拉高，超出"典型"表现。因此下方同时列出中位数，通常中位数更能代表一般情况。
  • 成分股存在幸存者偏差。 回测统一使用了当前的标普500/纳斯达克100成分股名单，而非每个历史日期的真实成分股名单——这是常见的简化处理方式，会带来轻微的幸存者偏差。
  • 阈值越高，样本量下降越快。 70分以上的样本量相对充足；90分以上在拥有完整12个月后续窗口的样本不足600条，数据量偏薄，其结果只能作为方向性参考。

03b — 低评分能否预测下跌？

该评分并非对称信号

诚实的结论是：这是一个微弱且不稳定的下行信号，远不及上行信号那样有力。 在中期（3–9个月），低评分确实呈现出真实但很小的负向偏离（中位数超额约−0.4pp至−2pp之间）。 但到12个月时，这种偏离会减弱甚至转为正值，且每个周期的胜率都维持在56–66%的多数区间——亏损率从未接近50%，更不用说超过50%。 对比一下量级：评分≥80档的12个月中位数超额是+17.0pp；评分≤30档是−0.6pp。上行信号大约是下行信号的30倍。

这与其说是缺陷，不如说是一种结构性特征：该评分的每一项分量（RS、动能、突破、趋势、量压）衡量的都是"强势信号是否出现"，而非"弱势信号是否出现"。 低评分意味着这些强势信号没有触发——并不意味着相反的信号（破位、派发、持续恶化）正在发生。 将这些同属"衡量优秀程度"的分量以其他方式重新组合（已针对下文的贝佐拉持续度与贝佐拉信心指数进行测试）也不会改变这一点——它们的低分端呈现的是同样微弱、逐渐消退的模式，而非更清晰的下行信号。 请将低评分理解为"当前未显示强势"，而非"预示将要下跌"。

03c — 动能+评分（BaizMomentum）— 结果

动能强化权重是否真的有帮助？

动能+（BaizMomentum）是上线的第二项评分，采用另一套权重—— RS 40% / 动能 35% / 突破 15% / 趋势 5% / 量压 5%——比默认贝佐拉评分权重（30/25/20/15/10）更偏重趋势跟随。 它使用的是看板上已有的同一批分项评分，只是权重比例不同。下图比较两个评分各自在自己的≥70/≥80/≥90阈值下的12个月中位数超额—— 该权重方案的完整筛选过程见下方权重对比一节。

03d — 持续度（BaizPersist）— 结果

平滑、持续的评分是否优于单日读数？

贝佐拉持续度（BaizPersist）是该股票自身贝佐拉评分过去21个交易日（约1个月）的滚动平均值—— 并非分项权重的另一种组合，而是同一评分随时间平滑后的读数。它是下方信心指数的构建基础， 也作为看板上的独立一列展示。由于它是0–100分的滚动平均值，很难触及最高分界线（本次样本中没有任何一个股票-交易日的21日滚动平均达到过≥90）， 因此测试的是≥30/≥50/≥70，而非贝佐拉评分所用的≥70/≥80/≥90。

03e — 信心指数（BaizConviction）— 结果

奖励"持续强势"而非仅看当天分数，是否有帮助？

信心指数（BaizConviction）= round(sqrt(贝佐拉评分 × 贝佐拉持续度))， 将当日评分与上方持续度（该股票自身过去21个交易日的平均评分）相结合。 其设计目的是奖励那些今天表现强势、且近期持续保持强势的股票，而非单日突然冲高——两者都要等该股票积累满一个月的历史数据后才有值。 由于信心指数没有天然对应的≥70/≥80/≥90分界线，我们改用样本量匹配的方式与贝佐拉评分对比： 针对贝佐拉评分的每个阈值，为信心指数选取一个使两组样本量（几乎）完全相等的分界线——这是在样本大小完全一致的前提下，比较"用不同方式定义的同等规模分组"表现是否更好。

12个月中位数超额，样本量匹配分组。此次运算将样本限定为拥有完整21个交易日持续度历史的记录（348,311条，占原始380,044条的一部分），因此本节中贝佐拉评分自身的数字与第03节的主要数字略有差异——两个评分都在完全相同的限定样本上重新计算，以保证对比公平。

与第03节线性度检验相同方法的分位数检验显示，信心指数的形态与贝佐拉评分高度相似：在6个月与9个月周期，10个分位区间中有8个呈递增（8/9）；在12个月周期的最低分位同样出现此前提到的部分回转——这是一种真实但并非完全线性的关系，并非该评分特有的缺陷。

诚实的结论是：在样本量匹配的前提下，信心指数确实优于纯贝佐拉评分。 相同的样本规模、相同的周期、相同的方法—— 信心指数在两个测试档位上12个月中位数超额均明显更大（≥70档等效规模下+9.3pp vs. +7.7pp；≥80档等效规模下+24.1pp vs. +16.2pp）。 这是本页唯一一项按样本量而非仅按阈值控制的评分对比——但仍然只是一次回测、一个市场周期，不保证未来同样成立。

04 — 测试不同权重组合

现行权重与其他方案的对比

我们用同样的分项评分数据，重新组合出另外五种权重方案，并放入与上文完全相同的回测流程中。这项测试只是在检验"权重设置是否重要"，而不是在检验"评分是否有效"——上文提到的市场环境依赖与小样本注意事项，在这里同样适用。

上文的动能强化权重方案，正是上线到正式看板的动能+（BaizMomentum）评分—— 完整对比详见上方的结果一节。

05 — 结论

贝佐拉评分家族目前的整体情况

本页所有测试——原始阈值、持续度、替代权重、以及三项衍生评分——都呈现出同样的形态： 持续保持高分与优于基准的后续表现相关，且该效应集中体现在"持续强势"而非"单日突破"，同时该效应并不对称—— 低分是一个微弱且不可靠的下行信号，并非上行信号的镜像。动能+、持续度与 信心指数是基于同一套底层数据提供的补充视角，而非对贝佐拉评分的替代； 其中信心指数是唯一一项在样本量匹配对比（而非仅按阈值对比）下明确优于纯贝佐拉评分的衍生评分。

以上均非保证。页面中的每一个数字都来自同一次回测、同一段持续牛市区间、经过存续偏差调整的历史数据—— 在得出任何结论前，请先阅读局限性部分的完整说明。
