常见 问题

关于贝佐拉平台使用、数据理解和订阅管理的常见问题解答。

入门指南
免费预览是什么？如何使用？ +
贝佐拉提供无需注册的免费预览，您可以直接访问精选市场信号——当日涨幅最大的 3 只股票——来评估数据质量、结构和平台实用性。

预览内容包括实时趋势图、多时间窗口滚动统计以及基本面数据（市盈率、市值、每股收益、行业对比），是对完整产品的真实体验，而非阉割版演示。
需要注册账户才能使用吗？ +
免费预览无需注册，可直接访问。

需要订阅付费账户才能解锁完整仪表盘，包括全部 500+ 只 S&P 500 和 Nasdaq-100 标的、所有时间窗口（2周至1年）、可排序列以及完整基本面数据。
7天免费试用是怎么运作的？ +
订阅后，您将获得 7天完整平台使用权——所有标的、所有时间窗口、所有功能，无任何限制。

您可以在试用期内随时通过 Stripe 客户门户取消，不会产生任何费用。7天后，订阅将自动按您所选方案（月付 $9.99 或年付 $99）续费。
✓ 试用期内不收费
平台与数据
数据是如何更新的？ +
市场数据在美股收盘后每日更新，通常在美东时间下午 5:00–6:00 完成处理。这确保了每日比较的一致性，避免盘中噪音干扰。

所有信号——价格变化、成交量行为、均线比率、趋势图和基本面数据——均反映最新交易日的收盘数据。
趋势图上的标记符号是什么意思？ +
每只股票都有一条1年价格趋势图，图上有两种特殊标记：

▲ 三角形——标记过去一年中成交量最大的交易日。绿色表示当日价格上涨，红色表示当日价格下跌。

● 圆圈（带光晕）——标记过去一年中单日价格变化最大的交易日。绿色表示当日成交量放大，红色表示当日成交量萎缩。

这些标记让您无需浏览数据表格，即可一眼发现异常活跃的时间点。
时间窗口功能展示什么？ +
贝佐拉支持六个滚动时间窗口：2周、1个月、3个月、6个月、9个月和1年，以及专门的1日视图。

1日视图显示今日价格变化、成交量变化及其与21日均线的比率——快速查看当日快照。

其他窗口显示该时间段内的总价格变化，以及该窗口内最大单日价格和成交量变动及其发生时间。

将鼠标悬停在仪表盘中任意列标题上，可查看其精确定义。
平台覆盖哪些股票？ +
贝佐拉覆盖 S&P 500 和 Nasdaq-100 的所有成分股——约 500+ 只流动性稳定的美国大盘股，数据质量达到机构级别。

平台专注于大盘股，以确保所有信号的数据一致性和可靠性。
贝佐拉是投资顾问或推荐服务吗？ +
不是。贝佐拉是一个数据智能平台——呈现结构化统计信号，而非投资建议。平台上的任何内容均不构成金融、投资、交易或专业建议。

所有信号均由自动化系统生成，不应被解读为买入、卖出或持有建议。做出投资决策前，请务必自行研究或咨询持牌金融顾问。
订阅与账单
如何管理或取消订阅？ +
所有订阅操作——升级、降级、取消和账单历史——均通过 Stripe 客户门户安全处理。

点击页面顶部的"管理账户"按钮，或登录后使用首页的账户菜单。变更在当前计费周期结束后生效。在试用期内取消不产生任何费用。
月付和年付有什么区别？ +
两种方案的功能完全相同——全部标的、全部时间窗口、趋势图和基本面数据一应俱全。

月付：$9.99/月——灵活，随时可取消。
年付：$99/年——相当于约 $8.25/月，比月付节省约 17%。

您可以随时通过 Stripe 客户门户切换方案。
免费试用结束后会发生什么？ +
7天后，订阅将按您注册时选择的方案自动续费（$9.99/月或$99/年）。费用通过您提供的支付方式扣取。

如果在试用期结束前取消，不会产生任何费用，访问权限立即终止。您可以随时重新订阅。
