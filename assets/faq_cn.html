关于贝佐拉平台您需要了解的一切——包括平台如何运作、如何管理您的订阅，以及如何最大化利用数据价值。

入门指南
免费预览是如何运作的？ +
贝佐拉平台提供无需登录或创建账户的免费预览。您可以立即访问一组精选的市场信号——即当日涨幅最高的3只股票——以便在订阅前评估数据质量、结构以及平台的易用性。该预览包含实时的 sparkline 走势图、多时间周期的滚动统计数据，以及基本面信息（市盈率 PE、市值、每股收益 EPS、行业板块）。这是真正完整产品的体验，而不是一个简化版演示。
需要注册才能使用吗？ +
免费预览无需注册。您可以直接访问精选的市场洞察页面 baizora.com/free.

要解锁完整仪表盘，则需要付费账户——包括全部 500+ 只 S&P 500 与 Nasdaq-100 成分股、所有时间周期（2周至1年）、可排序表格列，以及完整的基本面数据。
7天免费试用是如何运作的？ +
当您订阅后，您将获得对完整平台的 7天无限制访问权限 包括所有股票代码、所有时间周期以及所有功能，没有任何限制。

您可以在试用期间随时通过 Stripe 客户管理门户取消订阅，且 不会产生任何费用。7天结束后，您的订阅将根据您选择的计划（$9.99/月或$99/年）自动开始计费。
✓ 试用期间不会扣除信用卡费用。
平台与数据
数据是如何更新的？ +
市场数据在美股收盘后每日进行处理和更新，通常在 美国东部时间下午 5:00–6:00之间完成. 这确保了每日对比的一致性和稳定性，避免盘中噪音的影响。

所有信号——包括价格变化、成交量行为、移动平均比率、sparkline 图表以及基本面数据——均基于最新交易日的收盘数据生成。
sparkline 标记是什么意思？ +
每只股票都包含一个一年的价格趋势小型折线图（sparkline），并带有两个可视化事件标记：

▲ 三角形 — 标记过去一年中成交量最高的交易日。如果当天价格上涨则为绿色，如果下跌则为红色。

● 圆形（带发光效果） — 标记过去一年中单日价格涨跌幅最大的交易日。如果当天成交量上升则为绿色，如果成交量下降则为红色。

这些标记可以让您无需逐行查看表格，就能快速识别异常交易发生的时间点。在仪表盘中将鼠标悬停在“1Y Trend（一年趋势）”列标题上即可查看说明提示
时间窗口显示的是什么 +
贝佐拉平台支持六种滚动时间窗口： 2周、1个月、3个月、6个月、9个月和1年，以及一个单独的 1天视图.

1天视图 显示当日价格变化、成交量变化，以及它们相对于21日移动平均线的比率——用于快速查看每日概况。

其余时间窗口显示的是该时间段内的 累计价格变化 （例如过去3个月股价整体上涨或下跌的幅度），同时还会展示该区间内最大单日价格波动和成交量变化及其发生时间。

在表格中将鼠标悬停在任意列标题上即可查看该指标的具体定义。
贝佐拉平台覆盖哪些股票？ +
贝佐拉平台覆盖当前所有 标普500（S&P 500） 和 纳斯达克100（Nasdaq-100） — 总计约 500多只美国大型上市公司股票， 具有稳定的流动性以及机构级别的数据质量。

我们的平台专门专注于大型股，以确保所有信号在数据一致性和可靠性方面保持统一。
贝佐拉是金融顾问或投资推荐服务吗？ +
不是。贝佐拉是一个数据智能平台——它提供的是结构化的统计信号，而不是投资建议。该平台上的任何内容都不构成金融、投资、交易或专业建议。

所有信号均由自动化系统生成，不是买入、卖出或持有建议，也不应被这样解读。在做出任何投资决策之前，请务必自行研究或咨询合格的金融顾问。
订阅与账单
我如何管理或取消我的订阅？ +
所有订阅操作——升级、降级、取消以及查看账单记录——都通过 Stripe 客户门户（Stripe Customer Portal） 安全处理。

点击上方导航栏中的 “账户管理” 按钮，或登录后在首页使用账户菜单进入管理页面。所有变更将在当前计费周期结束时生效。在免费试用期间取消不会产生任何费用。
月付和年付方案有什么区别？ +
两个方案都包含相同的功能——可以完整访问所有股票标的、时间窗口、走势图（sparklines）以及基本面数据。

月付（Monthly）：$9.99/月——更灵活，可随时取消。
年付（Yearly）：$99/年——约合 $8.25/月，相比月付节省约17%。

您可以随时通过 Stripe 客户门户在不同方案之间切换。
免费试用结束后会发生什么？ +
7天免费试用结束后，您的订阅将自动按照您注册时选择的方案（$9.99/月或$99/年）继续生效。系统会通过您提供的支付方式进行扣款。

如果您在试用结束前取消订阅，则不会产生任何费用，并且您的访问权限会立即终止。您可以随时重新订阅。
