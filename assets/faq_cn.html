常见 问题解答

关于 Baizora 的一切 — 平台如何运作、如何管理订阅，以及如何充分利用数据。

快速入门
免费预览是如何运作的？ +
Baizora 提供免费预览，无需登录或创建账户。您可以立即查看精选市场信号——按日价格涨幅排名的前3只股票——在订阅前评估数据质量、结构和平台可用性。

预览包含实时走势图、多周期滚动统计数据和基本面数据（市盈率、市值、EPS、行业）。这是完整产品的真实体验，而非简化版演示。
使用 Baizora 需要注册账户吗？ +
免费预览无需注册。您可以直接访问 baizora.com/baizora_main_form_free_cn.html 查看精选市场数据。

解锁完整平台数据需要付费订阅——包括500+支标普500和纳斯达克100成分股、所有时间周期（2周至1年）、可排序列及完整基本面数据。
如何创建账户？ +
点击首页的登录，然后在登录页面点击免费注册。输入您的邮箱和密码（至少6位，包含至少一个大写字母和一个数字）。

注册后，我们会向您的邮箱发送一封验证邮件。您必须点击邮件中的链接才能登录，以确保账户安全和邮箱有效。
✓ 如未收到，请检查垃圾邮件文件夹
7天免费试用是如何运作的？ +
首次订阅时，您将获得7天完整的无限制访问权限——无任何限制，数据完整。

您可以随时通过账户页面或 Stripe 账单门户取消，不会产生任何费用。7天后，订阅将按您选择的方案自动续费（$9.99/月或$99/年）。

免费试用每个邮箱地址仅限一次。取消后以相同邮箱重新订阅将立即开始付费订阅，不含试用期。
平台与数据
数据是如何更新的？ +
市场数据在美股收盘后每日更新，通常在美东时间下午5:00–6:00之间。这确保了一致稳定的每日对比，不受盘中噪声干扰。

所有信号——价格变化、成交量行为、移动均线比率、走势图和基本面——均反映最新交易日的收盘数据。
走势图上的标记代表什么？ +
每只股票均包含一年价格走势图，带有两个视觉事件标记：

▲ 三角形 — 标记过去一年成交量最高的交易日。当日价格上涨为绿色，下跌为红色。

● 圆圈（带光晕） — 标记过去一年单日最大价格变动日。当日成交量放大为绿色，成交量萎缩为红色。

这些标记让您无需翻查数据表格，即可即时发现异常活动。悬停列表中的"年趋势图"列标题可查看提示。
时间周期窗口显示哪些信息？ +
Baizora 支持六个滚动时间周期：2周、1月、3月、6月、9月和1年，以及专用的1天视图。

1天视图显示当日价格变动、成交量变动及其与21日移动均线的比值——快速日常概览。

其他所有周期显示该期间的总价格变动，以及窗口内单日最大价格和成交量变动及其发生时间。

悬停列表中任意列标题可查看其精确定义。
Baizora 覆盖哪些股票？ +
Baizora 覆盖标普500和纳斯达克100的所有当前成分股——约500+支流动性稳定、具有机构级数据质量的美国大盘股。

平台专注于大盘股，以确保所有信号的数据一致性和可靠性。
Baizora 是投资顾问或推荐服务吗？ +
不。Baizora 是一个数据智能平台——提供结构化统计信号，而非投资建议。本平台上的任何内容均不构成金融、投资、交易或专业建议。

所有信号均由自动化系统生成，不应被解读为买入、卖出或持有建议。在做出投资决策前，请务必进行自主研究或咨询合格的金融顾问。
订阅与账单
如何管理或取消我的订阅？ +
所有订阅操作均可在两处进行：

1. 访问账户页面或点击此处，查看当前订阅状态、试用到期日期及取消订阅按钮。取消在当前计费周期结束时生效——在此之前您保留完整访问权限。

2. 账户页面上的管理账单按钮将打开 Stripe 客户门户，您可以在此更新支付方式、查看账单、切换方案或取消订阅。

在免费试用期间取消不产生任何费用——访问权限持续至试用期结束。
月付和年付方案有何区别？ +
两种方案包含完全相同的功能——完整访问所有股票、时间周期、走势图和基本面数据。

月付：$9.99/月 — 灵活，随时可取消。
年付：$99/年 — 约$8.25/月，比月付节省约17%。

您可以随时通过账户页面的 Stripe 账单门户切换方案。
免费试用结束后会发生什么？ +
7天后，订阅将按您选择的方案费率自动续费（$9.99/月或$99/年），通过您注册时提供的支付方式收费。

如在试用期结束前取消，不会产生任何费用，访问权限持续至试用期到期。您可以随时从方案页面重新订阅。
我已订阅但无法访问个人主页，该怎么办？ +
首先，请确认您的邮箱已验证——查收验证邮件并点击链接。未验证的账户无法登录。

如果邮箱已验证但登录后仍被重定向到账单页面，请尝试退出登录后重新登录。登录时会检查您的订阅状态。

如问题持续，请发送邮件至 support@baizora.com 并附上您的邮箱地址，我们将及时处理。
