常见 问题解答

关于 Baizora 的一切 — 平台如何运作、如何管理订阅，以及如何充分利用数据。

快速入门
免费预览是如何运作的？ +
Baizora 提供免费预览，无需登录或创建账户。您可以立即查看精选市场信号——按日价格涨幅排名的前3只股票——在订阅前评估数据质量、结构和平台可用性。

预览包含实时走势图、多周期滚动统计数据和基本面数据（市盈率、市值、EPS、行业）。这是完整产品的真实体验，而非简化版演示。
使用 Baizora 需要注册账户吗？ +
免费预览无需注册。您可以直接访问 baizora.com/baizora_main_form_free_cn.html 查看精选市场数据。

解锁完整平台数据需要付费订阅——包括500+支标普500和纳斯达克100成分股、所有时间周期（2周至1年）、可排序列及完整基本面数据。
如何创建账户？ +
点击首页的登录，然后在登录页面点击免费注册。输入您的邮箱和密码（至少6位，包含至少一个大写字母和一个数字）。

注册后，我们会向您的邮箱发送一封验证邮件。您必须点击邮件中的链接才能登录，以确保账户安全和邮箱有效。

如何进入个人主页？ +
拥有有效订阅后，可通过以下方式进入个人主页：

— 登录后 — 有效订阅用户将直接跳转至个人主页。

个人主页提供两个工具：完整扫描器（500+支股票，全部时间周期）和免费预览（前3大涨幅股票，无需登录，可分享给任何人）。

登录时，贝佐拉会自动检查您的订阅状态并相应跳转：

有效订阅用户 → 直接进入个人主页，所有功能即时可用。
新用户或未订阅用户 → 跳转至订阅页面，选择方案即可开始。

这样新用户登录后直接到达所需页面——距离开启免费试用只需一步，无需自行寻找订阅入口。
7天免费试用是如何运作的？ +
首次订阅时，您将获得7天完整的无限制访问权限——无任何限制，数据完整。

您可以随时通过账户页面或 Stripe 账单门户取消，不会产生任何费用。7天后，订阅将按您选择的方案自动续费（$9.99/月或$99/年）。

免费试用每个邮箱地址仅限一次。取消后以相同邮箱重新订阅将立即开始付费订阅，不含试用期。
平台与数据
数据是如何更新的？ +
扫描器在每个工作日（周一至周五）美股收盘后运行。数据供应商的盘后数据通常在美东时间下午6:00左右到达，因此个人主页一般在下午6–7点之间完成更新。数据供应商偶尔会出现延迟，这种情况较少见，但有时会发生——如果数据看起来未更新，稍等片刻后再刷新即可。周末数据延续最近一个周五的收盘数据。

价格、成交量、走势图和所有评分信号均反映最新交易日的收盘数据。基本面数据——每股收益、市盈率和行业——约每周从 SEC EDGAR 刷新一次。
收盘后显示的"初步"分析是什么？ +
在美股收盘（美东时间下午4:00）至完整定时扫描（下午6:30–7:00）之间，贝佐拉会自动运行一次初步"(beta)"分析，使用数据供应商的实时收盘数据。此期间，首页公告显示为"分析(初步)更新至：[今日日期]，完整数据下午6:30–7:00更新"。

初步分析将为500+支股票更新以下数据：
— 价格 — 今日收盘价
— 日价格变化 — 今日涨跌幅
— 成交量(M) — 今日成交量
— 日成交量变化 — 与昨日对比
— 价格/MA21 & 量/MA21 — 与21日均线的比值
— K线图 — 图表弹窗中新增今日K线柱

多周期统计（2周至1年）、评分及走势图在完整扫描完成前保持不变。完整扫描完成后（下午6:30–7:00左右），公告更新为"分析(最终)更新至：[日期]"，所有数据全部刷新。
市盈率和每股收益数据有多新？ +
每股收益直接来源于 SEC EDGAR XBRL 申报文件——这是美国所有上市公司向监管机构提交的权威 US GAAP 财务数据。EDGAR 在公司提交新的季报（10-Q）或年报（10-K）时更新，通常每季度一次。

扫描器每晚运行，并滚动刷新 EDGAR 基本面数据。实际上，每股收益变动较少——仅在公司提交新的 10-Q 或 10-K 时才会变化——因此数据始终与实际公司申报保持同步。

关于 GAAP 与调整后每股收益的说明：贝佐拉报告的是过去十二个月（TTM）摊薄 GAAP 每股收益。这与其他金融平台常见的"调整后"或"非 GAAP"数据不同。GAAP 每股收益包含一次性费用、重组成本和减值损失，而调整后数据则将其剔除。对于某些公司，这可能导致市盈率存在明显差异。
走势图上的标记代表什么？ +
每只股票均包含一年价格走势图，带有两个视觉事件标记：

▲ 三角形 — 标记过去一年成交量最高的交易日。当日价格上涨为绿色，下跌为红色。

● 圆圈（带光晕） — 标记过去一年单日最大价格变动日。当日成交量放大为绿色，成交量萎缩为红色。

这些标记让您无需翻查数据表格，即可即时发现异常活动。悬停列表中的"年趋势图"列标题可查看提示。
时间周期窗口显示哪些信息？ +
Baizora 支持六个滚动时间周期：2周、1月、3月、6月、9月和1年，以及专用的1天视图。

1天视图显示当日价格变动、成交量变动及其与21日移动均线的比值——快速日常概览。

其他所有周期显示该期间的总价格变动，以及窗口内单日最大价格和成交量变动及其发生时间。

悬停列表中任意列标题可查看其精确定义。
Baizora 覆盖哪些股票？ +
Baizora 覆盖标普500和纳斯达克100的所有当前成分股——约500+支流动性稳定、具有机构级数据质量的美国大盘股。

平台专注于大盘股，以确保所有信号的数据一致性和可靠性。
标普500和纳斯达克100成分股名单的准确性如何？ +
Baizora 的指数成分股名单来源于第三方数据平台，每个交易日收盘后更新。通常情况下，数据准确且及时。但若第三方来源错误地将某只股票列为标普500或纳斯达克100成分股，该股票将出现在 Baizora 的结果中，直至错误被修正。

针对成分股变动记录，我们运行自动往返检测机制：若某股票在3天内先被添加后被移除（或反之），该记录将被视为数据错误并自动从变动历史中撤销。

建议将 Baizora 的成分股名单视为可靠的近似参考，而非权威官方来源。如需查询权威名单，请参阅标普全球或纳斯达克官方渠道。
Baizora 是投资顾问或推荐服务吗？ +
不。Baizora 是一个数据智能平台——提供结构化统计信号，而非投资建议。本平台上的任何内容均不构成金融、投资、交易或专业建议。

所有信号均由自动化系统生成，不应被解读为买入、卖出或持有建议。在做出投资决策前，请务必进行自主研究或咨询合格的金融顾问。
我的自选股去哪了？收藏的股票消失了。 +
在未登录状态下使用 Baizora 时，您的自选股（★ 标记的股票）保存在浏览器本地存储中，不与任何账户绑定。这意味着：

— 清除浏览器缓存或 Cookie 会导致自选股丢失。
— 切换到其他浏览器或设备，自选股列表将为空。
— 使用隐私/无痕模式时，已保存的股票不会同步过来。

如需跨设备保留自选股，请登录您的 Baizora 账户。登录后，自选股将自动同步至云端，在任何已登录的设备上均可恢复。
订阅与账单
如何订阅方案？ +
订阅只需不到一分钟：

1. 如尚未注册，请先创建免费账户并验证邮箱。
2. 登录后，您将直接跳转至订阅页面。
3. 选择月付（$9.99/月）或年付（$99/年）并点击按钮——您将跳转至 Stripe 安全结账页面填写支付信息。
4. 支付确认后即可使用，完整个人主页访问权限立即生效，并享有 7天免费试用。

已有账户？直接前往订阅页面即可。
如何管理或取消我的订阅？ +
所有订阅操作均可在两处进行：

1. 访问账户页面或点击此处，查看当前订阅状态、试用到期日期及取消订阅按钮。取消在当前计费周期结束时生效——在此之前您保留完整访问权限。

2. 账户页面上的管理账单按钮将打开 Stripe 客户门户，您可以在此更新支付方式、查看账单、切换方案或取消订阅。

在免费试用期间取消不产生任何费用——访问权限持续至试用期结束。
月付和年付方案有何区别？ +
两种方案包含完全相同的功能——完整访问所有股票、时间周期、走势图和基本面数据。

月付：$9.99/月 — 灵活，随时可取消。
年付：$99/年 — 约$8.25/月，比月付节省约17%。

您可以随时通过账户页面的 Stripe 账单门户切换方案。
免费试用结束后会发生什么？ +
7天后，订阅将按您选择的方案费率自动续费（$9.99/月或$99/年），通过您注册时提供的支付方式收费。

如在试用期结束前取消，不会产生任何费用，访问权限持续至试用期到期。您可以随时从方案页面重新订阅。
我可以用相同的邮箱或信用卡再次获得免费试用吗？ +
不可以——免费试用同时受邮箱地址和信用卡双重限制：

相同邮箱：每个邮箱地址仅限一次免费试用。取消后以相同邮箱重新订阅将立即开始付费订阅，不含试用期。

相同信用卡：每张信用卡无论在哪个账户上使用过，均只能开启一次免费试用。已使用过的信用卡重新订阅将直接开始付费，不含试用期。

此政策旨在确保免费试用仅对真正的新用户公平开放。
退款政策是什么？ +
所有销售均为最终结果，我们不提供订阅费用退款，敬请谅解。

如果您不希望继续扣费，可随时在账户页面取消订阅——取消在当前计费周期结束时生效，此后不再产生任何费用。

我们强烈建议您充分利用7天免费试用期间评估平台，试用期间取消不会产生任何费用。

首先，请确认您的邮箱已验证——查收验证邮件并点击链接。未验证的账户无法登录。

如果邮箱已验证但登录后仍被重定向到账单页面，请尝试退出登录后重新登录。登录时会检查您的订阅状态。

如问题持续，请发送邮件至 support@baizora.com 并附上您的邮箱地址，我们将及时处理。
常见问题排查
我无法登录——一直报错或被跳转。 +
最常见的原因：

1. 邮箱未验证 — 注册后，您必须点击确认邮件中的链接才能登录。请检查垃圾邮件文件夹，或在登录页面点击"重新发送验证邮件"。

2. 密码错误 — 在登录页面使用忘记密码链接重置密码。重置邮件来自 noreply@baizora.firebaseapp.com，请注意查收垃圾邮件。

3. 无有效订阅 — 若登录成功但立即跳转到账单页面，说明您的账户没有有效订阅，选择方案即可继续使用。

如以上方法均无效，请发邮件至 support@baizora.com，并注明您的账户邮箱和错误描述。

请依次检查以下几点：

是否为工作日？ — 扫描器仅在周一至周五处理新市场数据。周末及美国市场假日显示最近一个周五的收盘数据，这是正常现象。

请按顺序尝试以下步骤：

1. 强制刷新 — Windows/Linux 按 Ctrl+Shift+R，Mac 按 Cmd+Shift+R，跳过浏览器缓存。

2. 退出后重新登录 — 从导航栏退出登录，再重新登录，刷新您的身份验证状态。

3. 换一个浏览器 — 如浏览器扩展程序或缓存状态有干扰，使用干净的浏览器（如 Chrome 无痕模式）可排查是否为环境问题。

4. 检查网络连接 — 个人主页通过实时API加载数据，网络不稳定可能导致空白。

如问题持续，请发邮件至 support@baizora.com，并说明您使用的浏览器和操作系统版本。
